# Super Disco Data Analysis App

A simple data analysis program for CSV files built with Python and Streamlit.

Features:
- Upload a CSV or Excel file
- View dataset preview and summary statistics
- Check missing values and duplicates
- Explore numeric columns with charts
- See correlations between numeric fields
- Generate quick business insights

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## Project structure

- `app.py` - main Streamlit dashboard
- `requirements.txt` - Python dependencies

## Notes

This is a starter project designed to help you analyze tabular data quickly.
